# E-Commerce Sales Analytics Dashboard

An interactive sales analytics project built with **PostgreSQL, SQL, Microsoft Power BI, and DAX**.

## Project Overview

This project analyzes e-commerce sales data to understand revenue, costs, profitability, product performance, and order status through an interactive Power BI dashboard.

## Tools & Technologies

- **PostgreSQL** — relational database
- **SQL** — data querying and analysis
- **Microsoft Power BI** — dashboard and visualizations
- **DAX** — business metrics and KPI calculations

## Key Performance Indicators

- Total Revenue
- Total Cost
- Total Profit
- Profit Margin
- Average Order Value (AOV)

## Dashboard Features

- Monthly revenue trends
- Revenue by product
- Profit by category
- Top products by revenue
- Orders by status
- Interactive date and category filters
- Sales analysis by country, if configured in the report

## Database Schema

The database includes five related tables:

- `customers`
- `categories`
- `products`
- `orders`
- `order_items`

## Business Questions

- Which products generate the most revenue?
- Which categories are the most profitable?
- How does revenue change over time?
- What is the distribution of order statuses?
- What is the average revenue per non-cancelled order?

## Data

This project uses a small sample dataset for learning and portfolio demonstration. Results are illustrative and should not be interpreted as representative of a real e-commerce business.
